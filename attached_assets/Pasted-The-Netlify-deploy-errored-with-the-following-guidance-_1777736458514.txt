Diagnosis
- Error type: pnpm CI install failure (ERR_PNPM_OUTDATED_LOCKFILE).
- Cause: The committed pnpm-lock.yaml is out of sync with the workspace package.json files. pnpm is running in "frozen-lockfile" mode in CI and detects that specifiers changed (it reports one removed dependency: @workspace/api-client-react). Netlify’s CI refuses to install when the lockfile is stale, so the build stops.

Solution
1) Verify workspace/package presence
- Check that the workspace package referenced (or removed) is intended. Confirm the package exists in your workspace config or that you intentionally removed it from package.json in one of your workspace packages (for example in the artifact workspace referenced by the error).
- If the package should exist, restore it in the appropriate package.json. If you intentionally removed/renamed it, proceed to update the lockfile.

2) Update and commit the lockfile (recommended)
- On your local machine, at the repository root run:
```bash
# (optional) ensure Corepack/pnpm version similar to CI:
corepack enable
corepack prepare pnpm@10.30.3 --activate

# install/update lockfile for the workspace
pnpm install
# or, explicitly at workspace root:
pnpm -w install

# commit the updated lockfile
git add pnpm-lock.yaml
git commit -m "chore: update pnpm-lock.yaml"
git push
```
- After pushing, Netlify CI will use the updated pnpm-lock.yaml and the frozen-lockfile check will pass.

3) Temporary/workaround (not recommended long-term)
- If you need an immediate deploy and cannot update the lockfile right now, change the build command in Netlify to run a non-frozen install (this bypasses CI safety):
  - In Netlify UI → Site settings → Build & deploy → Build settings, set the build command to:
  ```
  pnpm install --no-frozen-lockfile && <your normal build command>
  ```
  - Or add a pre-build script in your repo that runs pnpm install --no-frozen-lockfile.
- Note: This is a workaround; best practice is to update and commit the lockfile so CI remains deterministic.

If you suspect Node version issues later, follow Netlify’s docs for changing Node versions: https://docs.netlify.com/configure-builds/manage-dependencies/#node-js-and-javascript
